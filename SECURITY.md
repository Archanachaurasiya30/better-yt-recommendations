# Security policy

## Supported versions

Only the [latest release](https://github.com/r-afael/better-yt-recommendations/releases/latest)
gets security fixes.

## Reporting a problem

Please don't open a public issue. Report it privately through GitHub's
[reporting form](https://github.com/r-afael/better-yt-recommendations/security/advisories/new),
with the steps to reproduce it and what an attacker could do with it.

Examples of what to report:

- The extension sends what you watch, or anything else about you, anywhere.
- A web page can make the extension run code, read its storage or change its
  settings.
- The extension loads code from outside its own package.

You'll get a reply as soon as possible, usually within a week. Once a fix is
released, the report is published with credit to you, unless you'd rather stay
anonymous.
